# 看房
一些app有vr看房作为参考，也是很好的。

看房，需要从内、外两个方向看。

**对外**是通勤时间、周边是否嘈杂、小区环境、周边设施是否完善（商圈、购物中心、菜市场、药店、公园等）。

**对内**，主要关心房子朝向（决定光照），房间（主次卧大小差别是否悬殊、配套设备是否齐全（空调、冰箱、洗衣机、衣柜、床头柜、桌椅、WiFi、电视）、合租的室友是否好相处、卫生间里是日式马桶还是便池等等，细枝末节、但影响居住体验的方面。

另外，看房最好是白天去一次，晚上去一次，一来看光线是否充足，二来看周边是否吵闹（麻将馆警告⚠ ），同时也可以注意一下周边的菜市场、超市、便利店🏪等, 毕竟生活还是需要方便一些.



假如看了房觉得还不错，可以顺便检查一下房内各种设施是否有损坏: 去试试床板是否牢固，水龙头出水吗，灯泡亮不亮，便于在未来签合同之前，让对方安排修理。

关于看房时间。如果是跟中介在谈的话，那看房时间比较宽松，一般提前一天讲都可以。建议尽量提前预约，毕竟旺季好房抢手。

跟房东看房的话，可能多是在晚上或周末，需要注意安全，可以带一位朋友同去，安全第一。



看完了房，要是觉得各方面都合适，就到签合同环节啦。如果你并不能很快入住，又看中了这个房子, 我的建议是: 先交定金。交定金的目的,是为了确定你的租房意向，提前缴纳500-1000元不等的金额(和房东商量)。需要注意的是, 押金可以抵扣后续签合同时的租金, 但如果你中途又提出不租了——按惯例是不退的，因此交定金前一定要考虑清楚, 并且交押金时必须开具收据 / 立金额大写的收款字据，还可以记录收钱的人的身份证号，确保将风险降到最低。

最后, 要问一下允许的交租方式，推荐押1付1（月付）, 可以押1付3（季付）， 严重反对押1付6（半年付）和押1付12（年付）。

更新：我不小心遇上了包租公司，半年付，住了两个月就跑了......血亏几千块啊......



# 合租
合租需要注意的地方，合租主要是跟室友打交道。因此需要搞清楚Ta究竟是个怎样的人。

**假如你是二房主在找租客**，可以问

+ 为什么要合租
+ 是否有正当工作，在哪里上班
+ 作息是否规律
+ 抽不抽烟
+ 会不会带人回来过夜
+ 养不养猫
+ 爱不爱干净
+ 做饭水平怎么样
+ 公共空间怎么分配的



**假如你是租客在找合租的房源**，在找到潜在的房源之后，我建议再确认以下问题：

+ 房子原来的合同。包括租金、租期、支付方式等，确保你见过完整的原合同
+ 里面住了哪些人，都是干什么的、是否好相处等
+ 公共空间。公共空间怎么分配的，包括鞋架、饮水机、冰箱、厨房、阳台、卫生间、浴室等，都建议仔细检查（都是可以看出主人习性的地方），卫生是怎么分配打扫的
+ 费用。水费、电费、气费、物业、垃圾费等等，都是怎么分配的。
+ 其它让你感到可疑的地方，是否有对应合理的解释

最好是能通个电话，聊一聊，很多疑惑都能容易解开。





# 签合同
签合同前，请确认以下问题，且建议全程保留证据，录音或微信聊天记录截图（2020年5月新规：微信聊天记录也可以作为证据）：

![](https://cdn.nlark.com/yuque/0/2021/png/166008/1629997907256-4bfb30c6-8b54-4c59-a3b3-3eb04c604c9c.png)

1. 跟你签合同的人如果是二房东，请你弄清楚Ta签的合同是否允许转租、Ta是否已征求出租人（正房东）的同意。因为你要知道有些合同限制了转租，且法律规定`"承租人只有经出租人同意才有权处分该租赁物，否则即是无权处分"`

![](https://cdn.nlark.com/yuque/0/2021/png/166008/1629997942803-68f7fb49-2370-4909-8022-880bf3121f70.png)

2. **交租方式。**每月？or 每季度，微信 or 支付宝 or 银行卡转账？ 押金在退租后多久后退，什么情况下押金不能退
3. 签合同时需要出示双方的身份证原件，合同一式两份，建议提前索要合同，排除不合理条款。在签合同时需要注意关键部分即可
4. **基本常识：**涉及到钱时保留证据，例如转账时的备注，确保【性质明确、可追溯】

+ 术语：
    - `套一`：有一间卧室+厨房卫生间的房子
    - `套二`：有两间卧室+厨房卫生间的房子
    - `"押一付三"`，是对租赁行为中的押金和租金的一种交付方式的习惯性简洁的称谓，顾名思义即承租人以一个月房租作抵押，次先付三个月的租金，`"押一付三"`的首次付款是付4个月的房租。
    - `民水民电`，我国城市居民用电的一般价格是0.56-0.62元/度电
    - `商水商电`，普遍比`民用水电`贵。

![](https://cdn.nlark.com/yuque/0/2021/png/166008/1629999032296-18b7549c-7084-49ee-ab4c-02619f1372fd.png)

    - 出租房的户型：
        * **平层**户型，户型的一种，一般是指一套房屋的厅、卧、卫、厨等所有房间均处于同一层面上。
        * **跃层**户型，所谓跃层就是指住宅占有上下两层楼面，卧室、客厅、卫生间、厨房及其他辅助用房可以分层布置，上下层之间的交通不通过公共楼梯而采用户内独用小楼梯连接。
        * **复式**户型，在概念上是一层，并不具备完整的两层空间，但层高较普通住宅(通常层高2.8米)高，可在局部拘出夹层，安排卧室或书房等用楼梯联系上下，其目的是在有限的空间里增加使用面积，提高住宅的空间利用率
