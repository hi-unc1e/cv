# 视频->音频，从 mp4 中提取 mp3
:::info
mac 如何提取mp4 中的音乐？从 1:37:08 - 1:40:20

:::

在 macOS 上，你可以使用多种方法从 MP4 文件中提取音频，并且可以选择特定的片段。以下是使用 `ffmpeg` 工具的步骤，`ffmpeg` 是一个强大的多媒体处理工具，适用于 macOS、Windows 和 Linux。

### 步骤 1: 安装 `ffmpeg`
如果你还没有安装 `ffmpeg`，可以使用 Homebrew 来安装：

```bash
brew install ffmpeg
```

### 步骤 2: 提取音频片段
假设你的 MP4 文件名为 `input.mp4`，你可以使用以下命令提取从 1:37:08 到 1:40:20 的音频片段，并将其保存为 MP3 文件：

```bash
ffmpeg -i input.mp4 -ss 01:37:08 -to 01:40:20 -vn -acodec libmp3lame output.mp3
```

#### 解释：
+ `-i input.mp4`: 指定输入文件。
+ `-ss 01:37:08`: 指定开始时间。
+ `-to 01:40:20`: 指定结束时间。
+ `-vn`: 禁用视频流，只提取音频。
+ `-acodec libmp3lame`: 指定音频编码器为 MP3。
+ `output.mp3`: 输出文件名。

### 步骤 3: 检查输出
运行命令后，`ffmpeg` 会处理文件并生成 `output.mp3`，其中包含从 1:37:08 到 1:40:20 的音频片段。

### 其他方法
如果你更喜欢使用图形界面工具，可以考虑使用以下软件：

+ **Audacity**: 一个免费的开源音频编辑器，支持导入视频文件并提取音频。
+ **iMovie**: macOS 自带的视频编辑工具，可以导入视频并导出音频。

这些工具都可以帮助你轻松地从 MP4 文件中提取音频片段。



# 分离杂音
:::info
那么如何在 mac 上识别、分离mp3 中的不同音乐（有马路的声音，有音乐声）

:::



<font style="color:rgb(64, 64, 64);">有一些机器学习工具和库可以帮助自动分离音频源，例如 </font>`<font style="color:rgb(64, 64, 64);">Spleeter</font>`<font style="color:rgb(64, 64, 64);"> </font>

#### <font style="color:rgb(64, 64, 64);">使用 Spleeter:</font>
1. **<font style="color:rgb(64, 64, 64);">安装 Spleeter</font>**<font style="color:rgb(64, 64, 64);">:</font>

<font style="color:rgb(64, 64, 64);">你可以使用 Python 的包管理器</font><font style="color:rgb(64, 64, 64);"> </font>`<font style="color:rgb(64, 64, 64);">pip</font>`<font style="color:rgb(64, 64, 64);"> </font><font style="color:rgb(64, 64, 64);">来安装 Spleeter：</font>

```javascript
pip install spleeter
```

2. **<font style="color:rgb(64, 64, 64);">分离音频</font>**<font style="color:rgb(64, 64, 64);">:</font>

<font style="color:rgb(64, 64, 64);">使用以下命令来分离音频：</font>

```javascript

```

    - <font style="color:rgb(64, 64, 64);">这将生成多个文件，分别包含不同的音频源（如人声、鼓声、贝斯等）。</font>
