# 读书

# 工作
**工作一个月****：**像一头挨了锤的牛。我有时想到有人要“工作五十年”，就感到恐惧。你想啊，这周过了，还有下周，下周过了还有下下周，之后不是子子孙孙无穷尽了吗？出路在哪里，不工作就不能活了吗，为什么有人居然想工作五十年啊？

那时候是学生思维，直接把过程给忽略了，不该这么理解的。

要知道，在做这份工作的大部分时间里，我都能获得两样很重要的东西：成长、成就感，明白自己在做什么，知晓自己要去哪儿。

**工作三个月：**成为“社会人”以后，最大的转变，就是沟通变得更严谨、更简洁了。平日里的职场小白啊，总有一天会变成老司机吧。国庆前两天，我有幸被公司安排回学校宣讲，平时的记录跟思考，也足够应对个七七八八了。有点儿意思~

**工作六个月：**埋头苦干、不问是非，这份工作还蛮有意思的，又不是做同一份工，工作五十年很难吗？

# 其它
今年太紧绷了——年初疫情肆虐、“最难找工作年”以及发生在自己身上的租房公司跑路......

+ 租房的公司卷款跑路，使我难受了很久，朋友劝：“钱事小，一定得吸取教训”。
+ 出于隐私的考虑，关闭了微信“通过手机号添加微信”的功能，不得不说：很舒服。
+ 完整记账的第二年，感想：我花销有这么大吗，生活不易啊😭。
+ 在今年，我终于进入了心心念念的网络安全行业，有机会得以施展，虽难免浮躁，却也从前辈身上学到了很多：理性、耐心。如果说我在下半年有过一些小的成果，也应该先感谢他们；以后更要虚心请教才是。
+ 另一方面，工作以后，自然而然学会了做饭，朋友到家里做客，简单拼凑一桌小菜，度过一个嘻嘻哈哈的周末晚上，好不惬意！

希望新的一年里，无论是厨艺，还是漏洞能力，都能更上一层楼。

有时失意，常常满足，总是感恩。
